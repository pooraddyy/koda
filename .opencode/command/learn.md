description: Capture a small, verified project lesson from the current work
---

Extract only durable, project-scoped knowledge supported by the current source,
commands, or test result. A useful lesson is specific, redacted, and likely to
prevent a future mistake; it is not a transcript, secret, preference guess, or
substitute for reading the current code.

Before saving, state the proposed lesson, its evidence, likely scope, and an
expiration or review condition. Deduplicate against existing lessons and do not
save anything that could broaden permissions, reveal credentials, or conflict with
current user instructions.
